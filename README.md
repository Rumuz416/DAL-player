# 🎵 DAL Player

**DAL Player** is a modern, lightweight desktop music player application developed using an Electron and Python (Flask) architecture. Thanks to its user-friendly interface and standalone (portable) structure, it can be run anywhere without requiring installation.

---

## ✨ Features

* 🎧 **Modern & Minimalist Interface:** A stylish window design that is streamlined and free of cluttered menu bars.
* ⚡ **Portable Architecture:** Comes bundled with the Python backend; no separate Python installation is required on the host computer.
* 🚀 **Fast Startup:** Launches automatically, loading both the server and the frontend.
* 🖼️ **Custom App Icon:** A custom-designed application logo.

---

## 🛠️ Technologies

The project consists of two main layers:

* **Frontend:** Electron, HTML5, CSS3, JavaScript
* **Backend:** Python, Flask, PyInstaller

## 🚀 Development and Execution

You can follow the steps below to run or develop the project in your local environment.


### Requirements

* [Node.js](https://nodejs.org/) (v18 or higher)
* [Python 3.x](https://www.python.org/)

### 1. Clone the Repository

```bash
git clone https://github.com/USERNAME/DAL-Player.git
cd DAL-Player
```
```bash
# Node.js paketleri
npm install

# Python sanal ortamı ve bağımlılıklar
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
```
npm start
```
